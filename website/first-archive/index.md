# 首次归档

1. 启动应用并阅读免责声明。
2. 使用二维码或网页登录本人账号。
3. 打开“归档任务”，确认网络连接和本地可用空间。
4. 开始归档，应用会显示完成数量、进度与限流状态。
5. 在“归档内容”和“媒体”中核验结果，必要时导出 HTML。

## 遇到限流

停止频繁重试，等待应用倒计时结束后再继续。归档任务支持从已完成的位置恢复；提高请求频率不会提高完整度，反而可能增加账号风险。

## 导出前检查

无法从源数据确认的说说、评论或回复时间会显示为“时间未知”，不会用互动时间推测发布时间。如果旧版导出的 HTML 将这些记录显示为 1970 年，请升级应用后重新导出已有本地归档，无需清空数据或重新归档；原有 HTML 文件不会自动更新。

导出的文件可能包含他人的昵称、评论、图片或视频。分享、上传或公开前，请确认拥有相应授权并完成必要脱敏。
